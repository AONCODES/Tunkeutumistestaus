## Artikkelit

### Cracking Passwords with Hashcat

- Artikkelissa ladataan tarvittavat tiedostot ja ohjelmistot salasanojen purkua varten.
- Hashin analysointi `hashid -m <hash>` antaa ehdotuksia hash tyypistä.
- Salasanan purussa käytetään hashcattiä, `-m` parametrillä löydettyä moodia, hashtiivistettä ja haluttua sanakirjaa
- `-o solved` parametri lopussa tekee uuden tiedoston "solved" ja lisää tiivisteen sekä salasanana tiedostoon (jos salasana murrettu).
  
([Karvinen 2022](https://terokarvinen.com/2022/cracking-passwords-with-hashcat/))
### Crack File Password With John

- Artikkelissa ladataan tarvittavat tiedostot ja ohjelmistot Johnin käyttöä varten mm:
  - `Micro` teksti editori
  - `git` kloonausta varten
  - `zlib1g zlib1g-dev zlib1g-gst`	John ZIP support
- Ladataan Jumbo versio, tukee useita eri tiedostotyyppejä (git clonella)
- `john/src/` kansiossa tutkitaan ympäristö `./configure` -> luo makefilen `make` komennolle.
- ./configure tulosteen lopussa on make komento jolla compiloidaan John The Ripper lopuksi ajetaan `run`.
- zip tiedoston murtaminen 
  - ladatusta zip tiedostosta uusi hash tiedosto
  - John sanakirja hyökkäys hash tiedostoon
  - salasanan löytäminen ja pääsy zippiin.
  

([Karvinen 2023](https://terokarvinen.com/2023/crack-file-password-with-john/))
## Hashcat

Tehtävänä asentaa Hashcat ja testata murtaa salasana.

Asensin hashcatin ja hashid:n 
```
sudo apt-get install hashcat hashid
```
Tämän jälkeen loin uuden tiedoston SALASANATESTI ja sinne alikansiot hashes (tiiviste) ja dict (sanakirja). Alikansioihin lisäsin tekstitiedostoina sanakirjan ja hashit.

<img width="389" height="227" alt="Näyttökuva 2026-09-18 kello 14 44 51" src="https://github.com/user-attachments/assets/df395103-68ef-4746-b0f2-99f41295f27d" />

Tämän jälkeen analysoin hashin:

<img width="510" height="119" alt="Näyttökuva 2026-09-18 kello 14 46 48" src="https://github.com/user-attachments/assets/3824c99d-1e27-4314-acaa-de451c3303b0" />

Vastauksena erilaisia hash tyyppejä ja `-m` kertoo moodin numeron.

```bash
hashcat -m 0 9c00692cf8d9a4590ce2627ede636520 dict/dict -o solved
```

Käytin Mode: 0, tunnilta muistelin, että on yleisin noista vaihtoehdoista (testattava tiiviste Mode 0 = MD5. Laitoin perään vielä artikkelista tutun -o solved.

Hashcat ajon jälkeen tuli että All hashes found as potfile, eli on jo löytynyt, katsoin `--show` ja sain oikean merkkijonon ja hashin.

## John The Ripper

Asensin John The Ripperin ja muut tarvittavat [Teron sivujen](https://terokarvinen.com/2023/crack-file-password-with-john/) mukaisesti, mutta asennus ei mennyt läpi, koska (?) zlib-gst:tä ei ole saatavilla. Kokeilin ladata paketit ilman tätä ja sitten onnistui.

<img width="540" height="81" alt="Näyttökuva 2026-09-18 kello 15 35 03" src="https://github.com/user-attachments/assets/701c6ed2-287a-4394-996d-47407a441207" />

```
sudo apt-get -y install micro bash-completion git build-essential libssl-dev zlib1g zlib1g-dev libbz2-1.0 libbz2-dev atool zip wget   
```

Tämän jälkeen kloonattiin githubista John the Ripper, Jumbo versio.
`git clone https://github.com/openwall/john`

Lataus oli nopea ja vähän mietitytti että menikö se nyt läpi edes, mutta John kansio oli kuitenkin ilmestynyt Kaliin. Menin john/ ja edelleen src/ ja siellä annoin komennon `./configure`.

## PDF Tiedosto

Tein ensiksi PDF-tiedoston ja siirsin sen `/john/run` kansioon. Tämän jälkeen latasin `pdftk` sovelluksen Kaliin, softalla on mahdollista tehdä paljon asioita mm. asettaa salasanoja. ([Gökmen 2025](https://www.baeldung.com/linux/file-pdf-set-password))

Asetin salasanan. Tässä alkuperäisestä pdftiedostosta tehdään salattu versio ja sille asetetaan salasana (näkyvissä, ei hyvä).

<img width="668" height="81" alt="Näyttökuva 2026-09-18 kello 18 25 23" src="https://github.com/user-attachments/assets/bd085aec-9f40-4df5-9e29-2feb46aedc05" />

Tämän voi tehdä myös PROMPTilla niin salasana ei näy historyssa.
```
$ pdftk pdftiedosto.pdf output pdfsalasanalla.pdf user_pw PROMPT
Please enter the user password to use on the output PDF.
   It can be empty, or have a maximum of 32 characters:
```

## Tiiviste

Tehdään uusi käyttäjä Kaliin `tiivisteuser` ja asetin helpon salasanan. Lähdin sitten tutkimaan ja hieman oli ongelmia cat shadow:ssa (permission denied). Eli menin `/etc` ja cat shadow. Myöhemmin kokeilinkin sitten sudoa ja sehän avasi listan ja viimeisimpänä oli tuon tiivisteuserin hash.

Kopioin tuon hashin ja menin `/john/run` ja loin uuden tiedoston tiivisteuser.txt ja lisäsin hashin sinne.
Kokeilin sitten ajaa john tiivisteuser.txt:

<img width="425" height="79" alt="Näyttökuva 2026-09-18 kello 19 28 26" src="https://github.com/user-attachments/assets/fec66997-74d6-483e-a6de-430087408924" />

Tässä kohtaa kysyin AI:lta mitä tehdä, katsoin tiivisteen ja minulla oli vain se hash eikä sitä käyttäjänimeä mikä oli etc/shadow:ssa (kopioin siis vain sen hash osan enkä koko riviä). Kokeillaan lisätä tiivisiteuser: hashin eteen ajaa uudelleen john. **Tämä toimi**, jätin tässä vaiheessa johnin käyntiin jos löytäisi salasanan ilman antamaani sanakirjastoa. Tunnin se ruksutti mutta salasanaa "apple" ei löytynyt. Lisäsin sen omaan sanakirjaan ja ajoin uudestaan.

<img width="803" height="149" alt="Näyttökuva 2026-09-18 kello 20 39 16" src="https://github.com/user-attachments/assets/08b9f46a-2af2-4f61-a0fd-f14676d459b7" />

Kokeilin hashid:llä myös selvitellä jotain hashin tyyppiä mutta se ei tunnista sitä. Tekoäyltä vinkkejä ja ilmeisesti John versiossa ei ole yhtään **yescrypt** formaattia (hash alkaa $y$, kyseessä yescrypt).
